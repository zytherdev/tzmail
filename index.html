Quick start

A template should feel like code.

Keep the API readable. Keep the output polished. Start with a theme, tune the content, and let tzmail handle the email-specific details.

Read the docs ↗
import { EmailFactory, ThemeType } from '@zyther/tzmail';

const template = mailer.getTemplateService().createTemplate(
  ThemeType.ORBIT,
  'light',
  {
    header: { show: true, logo: { type: 'text', text: 'Acme' } },
    body: {
      title: 'Your update is ready',
      message: 'A clearer view of what matters.',
      buttonText: 'View update',
      buttonUrl: 'https://example.com/update',
      alignment: 'center'
    }
  }
);
